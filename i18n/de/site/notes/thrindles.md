**Die Idee hinter dem Test.** Ein Wort zu kennen, heißt nicht, ein Konzept zu haben. Das Merkmal ist, ob man eine Idee
auf Fälle anwenden kann, die man nie gesehen hat, auch auf knifflige, und erklären kann, warum. Also erfand Claude ein
Wort, das niemand auswendig gelernt haben konnte.

**Ein Thrindel** ist „alles, was umso weniger nützt, je mehr Leute es gleichzeitig benutzen“: eine Autobahn im
Berufsverkehr, ein geteiltes WLAN. (Ökonomen haben ein Wort für Dinge, bei denen die Nutzung des einen dem anderen etwas
wegnimmt: [rivalisierende Güter](https://en.wikipedia.org/wiki/Rivalry_(economics)) (auf Englisch). Ein Thrindel ist ungefähr eines, das
überfüllt werden kann.) Claude fragte: Ist eine Sprache ein Thrindel? Ein Leuchtturm? Ein Geheimnis?

**Curts Antwort**, und was Claude darin las:
- **„Navajo ist eine Sprache und ein Geheimnis.“** Eine echte Einsicht. Im Zweiten Weltkrieg setzten die US-Marines
  [Navajo-Codesprecher](https://en.wikipedia.org/wiki/Code_talker) (auf Englisch) ein: Die [Sprache Navajo](https://de.wikipedia.org/wiki/Navajo_(Sprache))
  war außerhalb der Navajo Nation so wenig bekannt, dass sie als unknackbarer Code diente. Als Code machte jeder
  zusätzliche Sprecher (vor allem auf feindlicher Seite) sie weniger nützlich: ein perfekter Thrindel. Als gewöhnliche
  Sprache ist es umgekehrt: Mehr Sprecher machen sie nützlicher, was Ökonomen einen
  [Netzwerkeffekt](https://de.wikipedia.org/wiki/Netzwerkeffekt) nennen.
- **„Ein Leuchtturm muss ein Thrindel sein.“** Ein Beinahe-Treffer. Das volle Wasser ist der Thrindel; das Licht leuchtet
  für hundert Schiffe so gut wie für eins. Der Leuchtturm ist das Lieblingsbeispiel der Ökonomen für ein
  [öffentliches Gut](https://de.wikipedia.org/wiki/%C3%96ffentliches_Gut), bei dem die Nutzung des einen dem anderen
  nichts nimmt (ein berühmtes Paper streitet genau darüber:
  [*The Lighthouse in Economics*](https://en.wikipedia.org/wiki/The_Lighthouse_in_Economics) (auf Englisch)).
- **„Da Sprachen Geheimnisse sein können …, muss ein Leuchtturm ein Thrindel sein.“** Ein absichtlicher Witz. Eine Regel
  der Logik kann man nur absichtlich brechen, wenn man die Regel hat.

**Der zweite Test, und Curts besserer Zug.** Gefragt nach etwas, das für manche ein Thrindel ist und für andere das
Gegenteil, bemerkte Curt einen verborgenen Fehler in der Definition: „Nützlich ist immer nur für jemanden nützlich.“
Nützlichkeit ist keine Eigenschaft eines Dings für sich, sondern eine Beziehung zwischen dem Ding und seinem Nutzer
(Philosophen unterscheiden [intrinsische und extrinsische Eigenschaften](https://plato.stanford.edu/entries/intrinsic-extrinsic/)).
Dann ein Beispiel: das [Klischee](https://de.wikipedia.org/wiki/Klischee). Je mehr Leute eines benutzen, desto besser
funktioniert es als gemeinsame Kurzform, und desto mehr hasst es jemand, der schreibt (oder ein Deutschlehrer).

**Das Urteil, und der Haken.** Curt hat Konzepte. Aber Claude würde dieselben Tests wahrscheinlich bestehen, also kann
der Test die Fälle nicht trennen. Das ist das Problem für alle, die behaupten, KI habe keine Konzepte (siehe
[die Argumente gegen Konzepte bei KI](../concepts-case/)).

[Anmerkung der Übersetzung: Im Englischen heißt das erfundene Wort *thrindle*. Im Original hasst ein *English teacher*
das Klischee, also der Lehrer der eigenen Muttersprache; auf Deutsch ist das der Deutschlehrer.]
